Separate Manga / Anime / Light Novel libraries with a bubble picker, and
RepoForge can now build sources for API-backed sites like Asura Scans.

Libraries
- Manga, Anime and Light Novels are separate libraries, so things stay sorted
  instead of piled together. Long-press the Library tab and a small bubble pops
  up above it to switch between them; your choice sticks after you leave or
  close the app. The Library tab icon, the "Add" button (Add Manga / Add Anime /
  Add LNs) and the Stats page all follow the current library, so each keeps its
  own titles, categories, totals and reading streak.

RepoForge
- RepoForge can now build a working source for sites that load their catalog
  from a JSON API — like Asura Scans, which used to come up empty because
  RepoForge only scraped the page HTML (those sites have none for it to read).
  It recognises the API and generates a source that calls it directly.
