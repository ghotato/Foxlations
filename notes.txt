A follow-up to the last release: Webtoons works properly now, and there's a new
per-source option for sites that treat phones differently.

Sources
- New "Request desktop site" option in a source's settings. Some sites send
  phones a cut-down page with the real content missing, so a source reading it
  finds nothing. Turn this on and that source asks for the full desktop page
  instead. Worth trying whenever a source comes up empty, or opens but lists no
  chapters.

RepoForge
- Webtoons: chapter lists now load once "Request desktop site" is on, and
  browsing works whether the site serves its phone or its desktop layout. The
  previous release only matched the phone one.

Notes
- Desktop mode steps aside on sites behind a Cloudflare check, so turning it on
  can't force you to solve the check again.
