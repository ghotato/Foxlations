RepoForge builds working sources for far more sites, plus better site
detection and a category-picker fix.

Sources (RepoForge)
- RepoForge now builds a source tailored to a site's engine instead of one
  generic template. Manga and novels: Madara, MangaThemesia, MMRCMS,
  FlameComics and LightNovel-WP. Anime: DooPlay, AnimeStream, HiAnime-style
  (Zorotheme) and FlixHQ (DopeFlix). The generic version couldn't load their
  chapters, pages or episode video; the tailored ones do — and anime embeds are
  handed to the built-in host extractors, now including MegaCloud (the host
  behind HiAnime). A generated Madara source was verified pulling full chapter
  lists and pages from a live site.
- RepoForge recognises many more site engines — seven additional manga themes
  and stronger anime fingerprints — so a site is detected correctly more often
  instead of falling back to a generic guess.
- RepoForge is still beta: it won't always get a source perfect, so check what
  it produces and tweak the selectors if a site doesn't come out right.

Windows
- Foxlations now builds for Windows, alongside Android and iOS. It is the full
  app, Cloudflare checks included. The one thing missing is the on-device text
  recognition and offline translation, which Google only provides on phones.

Sources
- Fixed: sources on a site that files its titles under something other than
  /manga/ — /title/, /comic/, /webtoon/ and so on — browsed the wrong address
  and came up empty. They now read the right one, and four new manhwa and
  manga sources that needed it have been added to the Foxlations repo.

Library
- Fixed: when a title had more categories than fit on screen, the "Add to
  Category" and "Edit Categories" sheets couldn't scroll, leaving the Save
  button off-screen. The list now scrolls and Save stays reachable.
